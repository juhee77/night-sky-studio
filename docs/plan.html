실제 불꽃쇼는 이렇게 짭니다

음악에 맞춘 불꽃쇼는 실제로도 이 앱과 비슷한 방식으로 짭니다. 연출가가 전용 소프트웨어에서 음악 파형 위에 발사 cue를 놓아 쇼를 짜고, 다 짜면 발사 스크립트로 뽑습니다. 이 스크립트를 전자 점화 장치에 넣으면, 장치가 발사 위치마다 연결된 점화선에 0.01초 단위로 불을 붙입니다. 이 앱은 그중 연출가가 하는 일을 따라 하고, 점화 장치 대신 화면이 쇼를 재생합니다.

불꽃은 박자보다 먼저 쏩니다

불꽃 알은 발사통에서 나와 꼭대기에 닿을 때까지 몇 초가 걸리고, 그 순간 터집니다. 박자에 맞춰 터뜨리려면 그만큼 미리 쏴야 합니다. 실제 연출가도 터질 시각을 기준으로 짜고, 소프트웨어가 상품마다 정해진 상승 시간을 빼서 점화 시각을 계산합니다. 이 앱도 같은 방식으로 합니다.

지도 무대: 내가 고른 장소에서 쏘기 (7단계, 완료)

  1. 장소 찾기무대 설정의 「지도에서 고르기」로 지도를 열고 강, 호수, 바닷가를 찾습니다.
  2. 발사 위치 찍기물 위에 바지선과 지상 틀을 찍습니다. 지도 무대에는 다리가 없어서 나이아가라는 빠집니다.
  3. 관람석 찍기사람들이 볼 자리를 찍습니다. 첫 관람석에서 바라본 쪽이 무대 정면이 됩니다. 바지선마다 이 쇼의 가장 큰 알 안전거리 원이 그려지고, 발사장 평면도에서도 관람석과 겹치면 알려 줍니다.
  4. 배경 만들기화면에 보이는 건물 높이로, 관람석에서 보아 발사 위치 너머에 있는 건물만 스카이라인 실루엣으로 만듭니다. 관람석에서 발사 위치까지 실제 거리(미터)로 소리 지연과 보이는 크기가 정해집니다.
  5. 연출실로찍은 발사 위치가 시간표의 트랙이 됩니다. 이제부터는 세계의 무대와 똑같이 쇼를 짭니다.

지도는 MapLibre GL JS와 OpenStreetMap 데이터로 그리고, 타일은 키 없이 쓸 수 있는 OpenFreeMap을 씁니다 (OpenStreetMap 공식 타일 서버는 쓰지 않습니다). 지도 코드는 지도 창을 처음 열 때만 받아 옵니다. 정적판에서도 동작하고, 고른 무대는 쇼와 공유 링크에 담깁니다. 지도 무대 화면에는 "실제 불꽃 발사 계획용이 아닙니다"를 늘 띄웁니다. 안전거리 원은 게임용 근사치라 실제 규정과 다릅니다.

어떻게 만들까

화면과 소리

  • Vite + TypeScript. 모듈이 많아서 빌드 도구를 씁니다.
  • WebGL2로 입자를 그립니다. 휴대폰에서 동시 입자 1~2만 개를 60fps로 유지하는 것이 목표입니다.
  • 불꽃 계산은 미터 단위 3D 좌표로 하고, 2D 화면은 고정된 카메라로 그립니다. 관람석과 3D 카메라는 카메라만 바꿉니다.
  • 연기는 낮은 해상도의 별도 층으로 그려 비용을 줄입니다.
  • Web Audio API로 재생하고, 소리 크기 변화로 박자를 찾습니다. 내 음악 파일은 기기 안에서만 처리하고 어디에도 올리지 않습니다.

저장과 공유

  • 같은 쇼는 언제 틀어도 같은 화면이 나오게 만듭니다. 난수 시드를 고정하고, 계산도 고정된 시간 간격으로 돌립니다.
  • 작업 중인 쇼는 브라우저에 자동 저장합니다 (IndexedDB).
  • 공유 링크에는 쇼 데이터만 압축해 담고 음악은 넣지 않습니다.
  • 영상 저장은 미니게임 천국 사진 앱에서 쓴 MP4 만들기 방식(WebCodecs)을 다시 씁니다.

기술 메모 · v2 추가

만들기 전에 정해 둘 다섯 가지

  • 재현성은 시드만으로는 부족합니다입자 계산을 고정된 시간 간격(1/120초)으로 돌려야 60Hz와 120Hz 화면, 느린 휴대폰에서 같은 장면이 나옵니다. 영상 저장도 실시간 녹화가 아니라 한 프레임씩 계산해 인코딩해서 끊김이 없게 합니다. 0단계 렌더 시험에 이 구조를 같이 넣습니다.
  • 공유 링크와 내 음악링크에 음악이 없으니, 내 음악으로 만든 쇼를 받은 사람은 그 곡을 들을 수 없습니다. 선물용 쇼는 기본 곡을 쓰도록 안내하고, 내 음악 쇼는 받는 쪽에 "같은 곡 파일을 골라 주세요"를 띄워 길이로 맞는지 확인합니다. 곡이 없으면 영상 저장으로 보내도록 권합니다.
  • 링크 길이5분짜리 쇼에 발사가 수백 번 들어가면 압축해도 몇 KB가 됩니다. 쇼 데이터는 주소의 # 뒤에 담고(서버로 가지 않음), 시간은 앞 발사와의 차이를 정수로 담아 줄입니다. 메신저에서 링크가 잘리는지 2단계에서 확인하고, 잘리면 서버판의 짧은 링크로 해결합니다.
  • 박자 자동 찾기는 자주 틀립니다BPM이 두 배나 절반으로 잡히는 일이 흔합니다. 박자를 직접 두드려 맞추는 버튼과 시작 지점(offset) 슬라이더를 1단계에 같이 넣습니다.
  • 소리와 화면 맞추기화면 시각을 화면 갱신 시각이 아니라 오디오 시계(AudioContext.currentTime)에 맞춥니다. 블루투스 이어폰처럼 소리가 늦게 나는 경우는 outputLatency로 보정합니다. 영상 파일에 소리까지 넣는 기능은 Safari 지원이 불안해서 4단계에 여유를 둡니다.
배포 · v2 추가

두 가지 배포 형태

코드는 하나이고, 빌드를 두 가지로 합니다. 불꽃을 계산하고 그리는 엔진과 화면은 똑같이 쓰고, 저장과 공유를 맡는 부분만 바꿔 끼웁니다. 정적판에서 만든 쇼 링크는 서버판에서도 그대로 열립니다.

정적판

<아이디>.github.io/night-sky-studio
  • GitHub Pages에 올리면 끝입니다. push하면 GitHub Actions가 빌드해서 올립니다.
  • 저장은 브라우저 안(IndexedDB), 공유는 긴 링크.
  • 다른 기기로 옮길 때는 쇼 파일 내보내기와 가져오기.

별도 도메인 + API 서버 + DB

불꽃 공작소: 내 불꽃을 만드는 네 단계

실제 불꽃 알은 종이 공 안에 '별'이라고 부르는 화약 알갱이를 층층이 채운 구조입니다. 공작소는 이 구조를 그대로 따라가서, 단계를 하나씩 채우면 내 불꽃 한 발이 완성됩니다. 실제 연출가가 카탈로그에서 상품을 고르듯, 여기서 만든 불꽃도 상승 시간과 원가가 붙은 상품이 됩니다.

모양

별을 어디에 놓을까

  • 격자에 점을 찍거나 손가락으로 그립니다.
  • 하늘 불꽃은 하트, 별처럼 단순한 모양까지만 됩니다. 실제처럼 점이 많고 복잡할수록 형태가 무너집니다.
  • 글자와 로고는 '틀 만들기' 탭에서 지상 틀불꽃으로 만듭니다. 이름, 날짜, "LOVE".
  • 사진에서 윤곽선을 따 오는 기능은 마지막에 틀 만들기에 붙입니다.
층

몇 겹으로 쌓을까

  • 바깥 층과 안쪽 심(芯)을 따로 정합니다. 심이 있으면 가운데에 작은 원이 하나 더 피어납니다.
  • 층마다 색과 별 종류를 고릅니다. 꼬리 있는 별, 점 별, 반짝이는 별.
  • 색이 바뀌는 별: 빨강으로 피었다가 초록으로 지는 식으로 시간에 따라 색을 바꿉니다.
움직임

어떻게 퍼지고 질까

  • 퍼지는 속도, 아래로 늘어지는 정도, 사라지는 시간.
  • 깜빡임: 꺼졌다 켜졌다 하며 사라집니다.
  • 두 번 터지기: 퍼진 별이 다시 갈라지거나 작은 불꽃으로 한 번 더 터집니다.
시험 발사

쏴 보고 서랍에 넣기

  • 정면, 측면, 바람 있는 날로 바꿔 가며 시험 발사합니다. 모양 불꽃은 터질 때마다 방향이 달라서, 옆을 향하면 납작한 선으로 보입니다. 이것도 실제와 같습니다.
  • 마음에 들면 이름을 붙여 '내 불꽃 서랍'에 저장합니다. 연출실 팔레트에 바로 나타납니다.
  • 불꽃 코드를 복사해 친구에게 보내면 친구 서랍에도 들어갑니다.

의뢰 모드와 이어지는 방식

  • 신제품 개발: 공작소에서 만든 불꽃을 의뢰에 쓰려면 개발비를 냅니다. 대신 원가가 기본 불꽃보다 쌉니다.
  • 맞춤 의뢰: "회사 로고를 지상 틀불꽃으로 띄워 주세요" 같은 의뢰는 공작소에서 직접 만들어야 받을 수 있습니다.
  • 반응 기록: 내가 만든 불꽃을 쓴 쇼의 관객 반응이 쌓여, 어떤 불꽃이 잘 먹히는지 알 수 있습니다.

위험대응
휴대폰 성능0단계에서 먼저 검증합니다. 기기 성능에 맞춰 입자 수 상한을 자동으로 낮춥니다.
음악 저작권내 음악은 기기 안에서만 씁니다. 공유 링크와 서버에 음악을 넣지 않고, 기본 곡은 저작권 걱정 없는 음원만 씁니다.
축제·기업 이름장소 이름은 쓰되 특정 축제나 기업의 이름, 로고는 쓰지 않습니다. '불꽃축제'처럼 일반 명칭만 씁니다.
랜드마크 그림사진을 쓰지 않고 직접 그린 단순한 실루엣만 씁니다. 야간 조명 디자인이 보호받는 건물도 있으니 조명 무늬는 그리지 않습니다.
지도 무대를 실제 발사 계획에 씀"실제 불꽃 발사 계획용이 아닙니다"를 늘 띄우고, 안전거리는 게임용 근사치라고 밝힙니다.
지도 타일 비용과 규정OpenStreetMap 공식 타일 서버는 쓰지 않고, 무료 등급 타일 서비스나 직접 올린 타일 파일을 씁니다.
휴대폰에서 편집이 복잡함세로 휴대폰은 '무대를 탭해서 놓기'와 자동 연출 위주로 하고, 세밀한 편집은 가로 화면과 PC에서 합니다.
사실감과 재미의 충돌실제 값은 참고만 하고, 화면에서 보기 좋은 쪽을 우선합니다.
두 판이 서로 어긋남엔진과 쇼 파일 규격은 하나만 둡니다. 정적판 링크를 서버판에서 여는 테스트를 CI에 넣습니다.
갤러리 악용 (서버판)글자 불꽃에 욕설이나 개인정보가 들어갈 수 있습니다. 신고·숨기기와 금칙어 검사를 갤러리와 함께 넣습니다.

시작 전에 고를 것

  • 정함레포 이름night-sky-studio. 로컬 폴더도 같은 이름으로 바꿨습니다.
  • 정함배포 형태정적판과 서버판 둘 다. 코드 하나, 빌드 두 가지.
