# 불꽃 종류·공방 효과 점검표

코드의 동작이 실제 불꽃의 원리와 맞는지 하나씩 대조한 표입니다 (2026-11-01, #144).

**판정:** 맞음 / 고침 / 그대로 (실측 자료는 못 찾았지만 알려진 모습과 어긋나지 않음)

크기, 상승, 별 비행의 계산 근거는 `packages/engine/src/catalog.ts`와 `flight.ts`의 주석에 있습니다.

## 공방 효과

| 효과 | 지금 동작 | 판정 |
|---|---|---|
| 꼬리 별, 점 별, 반짝이, 버들, 브로케이드, 카무로 | 위 표의 종류와 같은 계산. 숯이 많은 별은 저항 2배 | 맞음 |
| 낙엽 별 | 저항 10배로 작게 터지고 천천히 떨어짐 | 고침 |
| 크래클, 허머, 피시, 휘슬 별 | 위 표의 효과와 같음 | 그대로 |
| 색 변화 | 별의 층이 타면서 색이 바뀜 | 맞음 |
| 색 8가지 | 금·흰(금속), 빨강(스트론튬), 초록(바륨), 파랑(구리), 분홍·청록·보라(혼합) | 맞음 |
| 파랑·보라의 어두움 | 공방에서 고급 재료가 아니면 어두워짐. 기본 불꽃은 따로 어둡게 하지 않음 | 그대로 |
| 켜지는 순서 | 도화선 길이가 달라 차례로 켜짐. 하늘 기준 위아래 차례는 없음 | 맞음 |
| 여러 단 터지기 | 칸을 나눠 아래 칸일수록 늦게 터짐 | 그대로 |
| 두 번 터지기, 십자 갈라짐 | 수명 끝에 작은 별로 갈라짐 | 맞음 |
| 깜빡임 | 빛이 켜졌다 꺼짐 | 맞음 |
| 늘어짐 | 별의 무게로 계산, 중력은 그대로 | 맞음 |
| 올라가며 꽃 피기, 갈라지는 줄기, 꼬리, 휘파람 | 상승 경로에서 작은 별이나 불티를 냄 | 맞음 |

## 게임을 위해 실제와 다르게 둔 것

- **허머·피시·낙엽의 흔들림:** 힘을 계산하지 않고 위치에 더합니다. 궤적의 큰 줄기는 물리 계산을 따릅니다.
- **나이아가라와 틀불꽃의 기본 길이:** 8초와 10초입니다. 실제 지속 시간은 자료를 찾지 못했고, 시간표에서 조절합니다.
- **메아리:** 건물까지의 거리로 계산하지 않은 연출입니다.

## 자료를 찾지 못한 것

- 케이크 상승 시간 (3초는 계산값)
- 허머, 틀불꽃, 불티 알갱이의 수치
- 터질 때 별의 속도
